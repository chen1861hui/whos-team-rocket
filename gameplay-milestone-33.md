Zapdos uses one actual own kind:event/zapdos-punishment card with cardId-only input. It includes all living original actives, from the next trainer through the user last; no distance/Dodge/command response. Each target trainer judges once through the shared Drought/replacement pipeline. Only a final thunderstorm hits; other results or an empty supply give no damage. Base damage is the current level of the original active at judgment settlement, before target receiving modifiers. A replaced or defeated original never passes the hit to a reserve. Nested damage effects/rescue resolve before continuing the queue. The user's active is a recipient at the end, not a damage source.

Both use the shared event channel with explicit external source name, null Pokémon/trainer source IDs and a separate card actor.
