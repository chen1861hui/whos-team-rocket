# 谁是火箭队？ / Who’s Team Rocket?

一款支持多人联机、AI 和观战的宝可梦桌游。玩家各选一只出战宝可梦和一只后备，通过招式、道具和事件争取各自阵营的胜利。

## 玩法

- **原版身份局** 支持 3–6 人，也可与 AI 进行练习对决。
- **公开组队** 支持 2–30 人的偶数房间，可随机分队或按座位分队。
- **扩展** 可选关都城都巡回、丰缘天气研究或混用牌包。房主可在开局前选择场景和规则。

各模式的开局条件、回合流程和胜利条件见[规则书](GAME-RULEBOOK.md)。游戏内的规则书会随当前房间设置更新。

## 本地运行

需要 Node.js 22 或更高版本。在仓库根目录执行以下命令。

```sh
cd app
npm ci
npm start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。新建房间后，其他玩家可通过房间码加入。本机测试多人对局时，可用不同浏览器标签页加入同一个房间。

## 开发

在 `app/` 运行 `npm test`。服务端和对局结算位于 `app/server/`，前端及运行时美术资源位于 `app/public/`，自动测试位于 `app/test/`。截图、验收记录和研究资料保存在仓库之外。
