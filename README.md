# 谁是火箭队？

宝可梦主题的多人在线桌游。每位训练家选择一只出战宝可梦和一只后备，使用招式、道具和事件为自己的阵营争取胜利。支持 AI 和观战。

## 玩法

- **原版身份局**｜3–6 人，另有一人对 AI 的练习对决。
- **公开组队**｜2–30 人，偶数开局。可随机分队或按座位分队。
- **扩展牌包**｜关都城都巡回、丰缘天气研究，以及两包混用。

[查看完整规则](./GAME-RULEBOOK.md)

## 本地运行

需要 Node.js 22 或更高版本。在仓库根目录执行以下命令。

```sh
cd app
npm ci
npm start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173) 创建房间，其他玩家用房间码加入。

在 `app/` 中运行 `npm test` 执行测试。
