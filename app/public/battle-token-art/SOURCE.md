# Pixel art for battle statuses

- Burn, confusion, poison and sleep use frames from [Pokémon Mystery Dungeon: Red Rescue Team](https://github.com/pret/pmd-red/tree/master/graphics/status), archived by the pret/pmd-red decompilation project.
- Paralysis uses [the electricity animation](https://github.com/pret/pokeemerald/blob/master/graphics/battle_anims/sprites/electricity.png) and flinch uses [the overworld exclamation mark](https://github.com/pret/pokeemerald/blob/master/graphics/field_effects/pics/emotion_exclamation.png) from Pokémon Emerald as visual symbols.
- Power, Defense and Speed reuse the existing X Attack, X Defense and X Speed sprites in play-card-art.
