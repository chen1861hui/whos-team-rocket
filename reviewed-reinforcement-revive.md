Each reinforcement half gives one matching marker to an active Pokémon that lacks it. The player can target any living active Pokémon during Play. A suppressed marker still counts as present. Different markers can coexist. The shared combat rules handle suppression, distance, damage, and marker removal. Each tool spends the whole physical pair for one effect.

Revive targets a formally defeated Pokémon belonging to a trainer still in the battle and restores it to 2 HP. Defeat already clears status, reinforcement, and held items. Revive changes the HP and defeat flag of the existing Pokémon in its current slot. In the usual flow that Pokémon is the reserve after forced deployment, so its trainer can later switch it in normally. The Potion half remains available for healing or during fainting settlement. Both halves share the same physical card.

The card catalogue includes the reviewed tool text and observed weather. Tests use actual split-card objects in isolated scenarios. The default preview deck still uses the labeled command and Dodge fixture pending a verified retail manifest.
